reclab

A self-hosted platform for reasoning about, configuring, and benchmarking recommendation system architectures. It profiles your data, ranks candidate architectures with a plain-language rationale, then actually trains and evaluates them so you can check that reasoning against real results instead of just trusting it.

  • Three architectures in plain NumPy — matrix factorization, SASRec, hybrid LLM re-ranker
  • Validated end-to-end on MovieLens 100K and Amazon Reviews 2023
  • FastAPI + React UI with async training jobs and run history
  • 150+ automated tests, including a Playwright end-to-end suite
